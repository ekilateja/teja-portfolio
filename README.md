# teja-portfolio

Production web distribution of **Ekila Teja**'s Product Design Portfolio, built with Flutter Web.

🌐 **Live Site**: [https://ekilateja.github.io/teja-portfolio/](https://ekilateja.github.io/teja-portfolio/)

---

### Features
- **Entro8 Case Study**: AI-augmented community growth platform (0 to 10k users)
- **Moving Food Case Study**: Fleet delivery tracking & dynamic route engine
- **tejx Case Study**: 90-day momentum & accountability duel platform
- **Interactive Lightbox Zoom**: High-resolution inspectable mockups and telemetry data
- **Responsive Layout**: Fluid cross-platform support across desktop and mobile
